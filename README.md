# Tidal Memory

https://github.com/user-attachments/assets/739e32e3-6f50-49a2-8769-3efac040b465

Tidal Memory turns a projected floor into shallow night water full of glowing plankton. Step on it and a real wave goes out from your foot, and whatever the wave shakes hard enough lights up, which is exactly what dinoflagellates do. The flash is gone in a second, but a dimmer trace hangs on for eight, and the water is carrying that trace the whole time, so your footprint never stays a footprint. The floor remembers you, badly, and then not at all. The currents aren't blobs either. They're a web of filaments meeting at junctions and closing into cells, closer to a neural network diagram than to anything in a bay. Built in Unity, mouse now, floor LiDAR later.
